# Shannon: channel model

`source → encode → channel → noise → decode → destination → feedback`

- Source: need, observation, or decision.
- Encode: prose, code, plan, or action.
- Channel: system, team, tool, or conversation.
- Noise: ambiguity, bugs, drift, incentives, missing context, or model error.
- Decode: person or system that must act correctly.

Complexity is redundancy. Keep it only when it removes more noise than it adds. Use tests, validation, provenance, and explicitness for money, security, concurrency, parsers, data, irreversible actions, and handoffs. Redundancy everywhere bloats; nowhere loses data.

Optimize receiver decisions, not message length. Name actor, change, success signal, conditions, uncertainty, and recovery. Encode known rules deterministically. Interpret ambiguous inputs only with evidence and ownership.
