# Shannon: channel model

`source → encoder → channel → noise → decoder → destination → feedback`

- Source: need, observation, or decision.
- Encoder: prose, code, plan, or action.
- Channel: system, team, tool, or conversation.
- Noise: ambiguity, bugs, drift, incentives, missing context, model error.
- Decoder: person/system that must act correctly.

Complexity is redundant encoding. Keep it only when it removes more noise than it adds. Tests, validation, provenance, and explicitness correct errors; use them for money, security, concurrency, parsers, data, irreversible actions, and handoffs. Redundancy everywhere bloats; nowhere loses data.

Optimize receiver decisions, not volume. Name actor, change, success signal, conditions, uncertainty, and recovery. Encode known rules deterministically; interpret ambiguous inputs only with evidence and ownership.
