# Shannon: channel model

`source → encoder → channel → noise → decoder → destination → feedback`

- Source: need, observation, or decision.
- Encoder: prose, code, plan, or action.
- Channel: system, team, tool, or conversation.
- Noise: ambiguity, bugs, drift, incentives, missing context, model error.
- Decoder: person/system that must act correctly.

Complexity is redundant encoding. Keep it only when it removes more noise than it adds. Tests, validation, provenance, and explicitness are error correction; use them for money, security, concurrency, parsers, data, irreversible actions, and handoffs. Redundancy everywhere is bloat; nowhere is data loss.

Optimize receiver decisions, not volume. Name actor, change, success signal, conditions, uncertainty, and recovery. Known rules want deterministic encoding; ambiguous inputs may use interpretation, but still need evidence and ownership.
