# Shannon: channel model

`source → encode → channel → noise → decode → destination → feedback`

- Source: need, observation, decision. Encode: prose, code, plan, action.
- Channel: system, team, tool, conversation. Noise: ambiguity, bugs, drift, incentives, missing context, model error.
- Decode: person or system that must act correctly.

Complexity is redundancy. Keep it only when it removes more noise than it adds. Use tests, validation, provenance, explicitness for money, security, concurrency, parsers, data, irreversible actions, handoffs. Redundancy everywhere bloats; nowhere loses data.

Optimize receiver decisions, not message length. Name actor, change, success signal, conditions, uncertainty, recovery. Encode known rules deterministically; interpret ambiguous inputs only with evidence and ownership.
