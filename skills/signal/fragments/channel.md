# Channel

`source → encode → channel → noise → decode → destination → feedback`

Map: need/observation/decision → prose/code/plan/action → system/team/tool/conversation → ambiguity/bugs/drift/incentives/missing context/model error → responsible actor.

Keep redundancy only when it removes more noise than it adds. Money, security, concurrency, parsers, data, irreversible action, and handoff may require tests, validation, provenance, or explicitness.

Optimize correct receiver action: name actor, change, conditions, success, uncertainty, recovery. Encode known rules deterministically; resolve ambiguity with evidence and ownership.
